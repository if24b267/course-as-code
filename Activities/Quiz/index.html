    Quiz

    Note

    The Quiz activity is by far the most extensive activity supported by Course as Code, as a quiz can, in turn, contain various question types, all of which require their own structure within the data model.

    As with all other activities discussed so far, the Quiz is also an activity that extends the abstract Activity class. A quiz broadly consists of two elements:

    • The Quiz activity itself and parameters that describe it in more detail (e.g., OpenTime, CloseTime, GradeToPass, AllowedAttempts, etc.)
    • A series of questions of various types

    The parameters that define the quiz's metadata are the properties of the Quiz class (refer to the Description Attributes in the Model class for a precise description of all available parameters).

    Furthermore, every quiz is associated with SafeExamBrowserSettings. The Safe Exam Browser (SEB) is a specialized browser that blocks access to many OS functions and other websites to make cheating more difficult for students. For each quiz, it can be configured whether SEB is required to conduct the quiz and how SEB should be configured for that specific quiz - this information is stored in the SafeExamBrowserSettings class.

    The core of every quiz are the quiz questions that students must answer. A quiz can contain any number of questions of any type, and a specific question can also appear in multiple quizzes.

    Question Types

    Info

    There are certain parameters that are required for all question types. These include, for example, their name (for internal representation in the QuestionBank), their text (i.e., the question itself - all questions have a question statement), or general parameters, such as whether the question is a draft or a finished question. These parameters are stored in the abstract parent class Question, the subclasses then implement only those parameters that are necessary for that particular type of question.

    MultipleChoice Question

    Multiple Choice Questions are the most common and frequently used type of question in Moodle. They consist of a question statement (QuestionText in the base class) and a set of possible answer options (MultiChoiceAnswer).

    For each MultiChoiceAnswer, the AnswerText can be defined, along with an AnswerGrade that determines the value of that answer.

    Example

    To create a multiple-choice question with only one correct answer, the AnswerGrades must be set as follows:

    • Answer Text = Correct Answer | AnswerGrade = 1
    • Answer Text = Incorrect Answer | AnswerGrade = 0
    • Answer Text = Incorrect Answer | AnswerGrade = 0

    In this case, the student would receive full marks for selecting the correct answer, but also if they blindly check all answers. To prevent this, a negative AnswerGrade must be assigned to the incorrect answer options (so that their selection leads to deductions).

    • Answer Text = Correct Answer | AnswerGrade = 1
    • Answer Text = Incorrect Answer | AnswerGrade = -1/2
    • Answer Text = Incorrect Answer | AnswerGrade = -1/2

    Warning

    It is absolutely necessary that the positive AnswerGrades sum up to exactly 1 - otherwise, the question will not be recognized correctly by Moodle. For example, if there are 3 correct and 1 incorrect answer option, this must be defined as follows:

    • Answer Text = Correct Answer | AnswerGrade = 1/3
    • Answer Text = Correct Answer | AnswerGrade = 1/3
    • Answer Text = Correct Answer | AnswerGrade = 1/3
    • Answer Text = Incorrect Answer | AnswerGrade = -1/3 (1)

    Note that for the positive answers, an AnswerGrade in the form of a fraction (⅓) was chosen instead of a decimal (e.g., 0.33). This is absolutely necessary for irrational numbers so that Moodle sums them up correctly. (Internally, the fractions are of course stored by C# as floats and thus again as decimals - however, the precision of a float is sufficient to make it clear to Moodle that it is a fraction.)

    1. Negative AnswerGrades do not have to sum up to 1; any value can be chosen.
      On the contrary: Negative AnswerGrades can even be values greater than 1, so that the user receives overall point deductions if they answer the question incorrectly.
    SingleChoice Question

    The Single Choice Question is a special form of the Multiple Choice Question, where only one of the given answers is correct (in contrast to Multiple Choice Questions where one or more answers can be correct). A question is marked as a Single Choice Question by setting the SingleChoice Boolean in the MultipleChoiceQuestion class to true and setting the AnswerGrade parameters accordingly.

    Info

    If the AnswerGrades are set such that only a single answer is correct, but the SingleChoice Boolean is left as false, only one answer to the question is correct, but the student can still select multiple answer options. If SingleChoice is set to true, the student can only select one answer when taking the quiz and not multiple.

    Dropdown Question

    The Dropdown question is internally referred to as a Matching Question in Moodle and, strictly speaking, consists of multiple sub-questions. The AnswerText of the parent Question class is displayed at the top as a heading, while the actual question consists of several sub-questions, namely the assignment of the correct selectable text to the given text.

    The DropdownQuestion type therefore consists of several DropdownSubQuestions, which represent the individual interaction possibilities for the user (in this case Java, C, Prolog, and Haskell). For each sub-question, the QuestionText and the CorrectAnswer are defined. To make answering the question more challenging, a series of WrongAnswers can also be specified.

    Bug

    The internal data model does not clearly represent how Dropdown Questions (or rather, Matching Questions) function in Moodle.
    Fundamentally, the question was designed as an assignment task. This means that every correct answer to a sub-question is also available as an answer option for all other sub-questions, but it is only correct for the one where it was specified as the CorrectAnswer.

    Example

    SubQuestion1: CorrectAnswer = "Miami"
    SubQuestion2: CorrectAnswer = "Florida"
    SubQuestion3: CorrectAnswer = "United States"

    Dropdown Menu for SubQuestion1: "Miami, Florida, United States"
    Dropdown Menu for SubQuestion2: "Miami, Florida, United States"
    Dropdown Menu for SubQuestion3: "Miami, Florida, United States"

    If additional incorrect answer options are provided, they are also available as answer options for all sub-questions, not just for the sub-question where they were listed in the WrongAnswer list.

    Example

    SubQuestion1: CorrectAnswer = "Miami", WrongAnswer = "Florida, Kansas"
    SubQuestion2: CorrectAnswer = "Washington", WrongAnswer = "Miami, United States"

    Dropdown Menu for SubQuestion1: "Miami, Florida, Kansas, Washington, United States"
    Dropdown Menu for SubQuestion2: "Miami, Florida, Kansas, Washington, United States"

    DragAndDropText Question

    The DragAndDropTextQuestion format refers to classic fill-in-the-blank questions where the user has to insert the correct word from a set of predefined words into the corresponding gap.

    This question type consists of a QuestionText (in the parent class Question) that can contain gaps, and multiple TextChoice elements, each assigned an ID and a Value (its content), which can be inserted into the cloze text.

    The QuestionText should be formulated as continuous text. Gaps can be defined using [[1]], where 1 is a sequential number for each gap and references the ID field of the TextChoice elements. The TextChoice element whose ID matches the number in the gap placeholder is considered the correct answer for that text position. TextChoice elements with an ID that is not referenced anywhere in the cloze text are not considered correct answers anywhere and act as distractors.

    Example

    The question from the example screenshot would be represented in the data model as follows:

    QuestionText = "In Linux, file permissions are controlled by three sets of access rights: [[3]], [[4]], and [[5]]. To view the permissions of a file, you can use the [[1]] command. Permissions are typically displayed as a string like rwxr-xr--, where each letter represents a different [[6]]."

    TextChoice elements:

    • ID = 1, Value = "ls -l"
    • ID = 2, Value = "chmod"
    • ID = 3, Value = "owner"
    • ID = 4, Value = "group"
    • ID = 5, Value = "other"
    • ID = 6, Value = "permission"
    • ID = 7, Value = "cd"
    • ID = 8, Value = "shutdown"
    • ID = 9, Value = "cat"
    • ID = 10, Value = "nano"

    A TextChoice can also be assigned to a specific Category to specify distractors individually per gap.

    Example

    The question from the example screenshot would be represented in the data model as follows:

    QuestionText = "The [[1]] is a type of system software that manages [[5]] and software resources, and provides common services for computer programs"

    TextChoice elements:

    • ID = 1, Value = "Operating System", Category = "A"
    • ID = 2, Value = "Compiler", Category = "A"
    • ID = 3, Value = "Microsoft Word", Category = "A"
    • ID = 4, Value = "Printer", Category = "A"
    • ID = 5, Value = "Hardware", Category = "B"
    • ID = 6, Value = "Internet", Category = "B"
    • ID = 7, Value = "Printing", Category = "B"

    CodeRunner Question

    Warning

    The documentation for CodeRunnerQuestions is currently incomplete and/or incorrect and needs to be revised.

    Description Question

    This question type is not a question in the traditional sense, as the student has no opportunity to enter an answer and receives no points for this question. It acts merely as a note that the student can view while taking the quiz (displayed as a question without an answer field). This can be used, for example, to provide students with specific resources such as mathematical formulas or other "cheat sheets".

    There are no specific parameters for questions of the Description type. Just like with every other question type, the QuestionName field from the parent class is used to designate the name of the "question" in the question bank. The QuestionText field from the base class is used for the content that should be displayed in the Description question.

    Warning

    A DefaultMark (= the value of this question in points, used for grading) can also be set for questions of the "Description" type, which factors into the calculation.

    For example, if DefaultMark = 3 is set, the Description question then contributes 3 points to point total of this quiz. However, since the student cannot enter an answer, they have no possibility of earning these 3 points - Description questions are always automatically scored with 0 points. Consequently, it becomes impossible for students to achieve the maximum score on the quiz.

    Therefore, DefaultMark = 0 should always be set for questions of the "Description" type.

    True/False Question

    With this question type, the student has only two options for answering: "True" or "False". Internally, this is a modified version of the Multiple Choice question that provides only 2 answer options. For this reason, the internal data model uses a similar structure:

    For every True/False question, a list of possible answer options is defined in Answers - there must be exactly two, a requirement enforced via Data Annotations. The first answer in this list automatically corresponds to the True option, and the second answer corresponds to the False option.

    Tip

    Internally, Moodle distinguishes between the answer text ("True"/"False") and the actual mapping to the Boolean values True and False. If you assign the AnswerText "False" to the first option in the list and "True" to the second, this does not change the internal mapping. The item with the answer text "False" will then correspond to the internal answer option True. The item with the answer text "True" will then correspond to the internal answer option False.

    If True were the correct answer for this question, the student would answer correctly by selecting "False" and answer incorrectly by selecting "True".

    Example

    var trueFalseQuestion = new TrueFalseQuestion
{
    QuestionId = 1,
    QuestionName = "Moodle inner workings",
    QuestionText = "Are moodle's inner workings sometimes a bit weird?",
    QuestionTextFormat = FormattingFormat.PlainText,
    DefaultMark = 1,
    CorrectAnswer = false,
    Answers = new List<MultiChoiceAnswer>
    {
        new MultiChoiceAnswer
        {
            AnswerText = "False", # Despite the text saying "False", this answer is actually the `True` option
            AnswerTextFormat = FormattingFormat.PlainText,
            AnswerGrade = 0.0f,
            AnswerFeedback = "You selected the answer with the correct text, but internally the other answer is the real `false` option",
            AnswerFeedbackFormat = FormattingFormat.PlainText,
        },
        new MultiChoiceAnswer
        {
            AnswerText = "True", # Since Correct Answer is set to false and this answer is actually the `False` option, the student has to select this answer to answer correctly
            AnswerTextFormat = FormattingFormat.PlainText,
            AnswerGrade = 1.0f,
            AnswerFeedback = "You have selected the answer with the wrong text, but internally it's the real `true` option so you got the points",
            AnswerFeedbackFormat = FormattingFormat.PlainText,
        },
    },
    Category = "Common Knowledge",
};

    Specifying the answer options in the Answers list makes it possible to set parameters such as AnswerGrade and AnswerFeedback.

    Failure

    AnswerText can also be set freely in this specific way, but its value must always be exactly "True" and/or "False", otherwise the question will not be displayed in Moodle.

    If there is no need to manually set AnswerGrade and AnswerFeedback, the list of Answers can also be left empty. In this case, "True" and "False" answer options are automatically generated, and CorrectAnswer determines which is the correct answer.

    Example

    var trueFalseQuestionNoList = new TrueFalseQuestion
{
    QuestionId = 2,
    QuestionName = "Moodle inner workings",
    QuestionText = "Are moodle's inner workings sometimes a bit weird?",
    QuestionTextFormat = FormattingFormat.PlainText,
    DefaultMark = 1,
    CorrectAnswer = true,
    Category = "Common Knowledge",
};
