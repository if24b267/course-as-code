Hyperbel

Synopis

Geben sie eine beschriftete Hyperbel aus!

Assignment

Schreiben Sie ein Programm, das vier ganze Zahlen a, b, c und d sowie eine Fließkommazahl e einliest und genau die angegebene Ausgabe erzeugt. Verwenden Sie zum Ausrichten ausschließlich Leerzeichen. Die Zahlen a, b, c und d werden oben, unten, links und rechts ausgegeben. b ist linksbündig, c rechtsbündig formatiert, Spaltenbreite jeweils 3. a und d sind rechtsbündig, die Spaltenbreite beträgt 11 Stellen. e ist ebenfalls rechtsbündig mit einer Spaltenbreite von 7 Stellen.

Beispiele

(Text in rot = Benutzereingabe)

Beispiel 1

a: 1
b: 2
c: 3
d: 4
e: 5.5

01234567890123456
\               /
 \ 00000000001 /
  \           /
2  | 005.500 |  3
  /           \
 / 00000000004 \
/               \

Beispiel 2

a: 111
b: 222
c: 333
d: 444
e: 12.23

 \ 00000000111 /
  \           /

  /           \
