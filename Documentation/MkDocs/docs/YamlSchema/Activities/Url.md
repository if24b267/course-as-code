# URL

Defines a URL resource.

## Properties

| Property | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `URL` | `string` | **Yes** | The external URL link. |

## Example
```YAML
Type: url
Name: Course as Code Documentation
Description: For more information about Course as Code, please refer to the official documentation.
URL: https://davimalu.github.io/course-as-code/
```
