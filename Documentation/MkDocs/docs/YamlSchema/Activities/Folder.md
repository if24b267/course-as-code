# Folder

Defines a folder resource containing multiple files.

## Properties

| Property | Type | Description |
| :--- | :--- | :--- |
| `VisibleToStudents` | `bool` | Whether the folder is visible to students. |
| `DisplayDescription` | `bool` | Whether the description is displayed on the course page. |
| `YamlFilePaths` | `List<string>` | A list of [YamlFile](File.md) paths (strings) to be included in the folder. |
