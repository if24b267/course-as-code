> 🛈 **Info**!
    This quiz serves as a showcase for the CodeRunner question type in Moodle. Instructors can provide a simple application skeleton along with test cases, and students must subsequently write code to fulfill the specific requirements of the assignment. The code is executed on the server, and the test cases automatically verify whether the student's answer was correct.
    CodeRunner is **not** natively supported by Moodle. For this quiz to work, please ensure that the [CodeRunner Plugin](https://moodle.org/plugins/qtype_coderunner) is installed on your Moodle instance.
